# Comparer les territoires

La vue **Comparer les territoires** (vue experte) permet de comparer plusieurs
territoires ou unités côte à côte.

## Utilisation

- Choisissez les territoires ou unités à comparer (captages, bassins versants, communes).
- Les vues comparées partagent les **mêmes filtres** : toute modification se répercute de
  manière cohérente sur l'ensemble des visualisations.
- La **visualisation simultanée** facilite la lecture des différences entre unités.

## Bonnes pratiques

- Comparez des unités de **même nature** (captages entre eux, BV entre eux) pour garder
  une lecture homogène.
- Utilisez le **tri selon un indicateur** pour ordonner les unités du plus au moins
  exposé et identifier les extrêmes.
- Recoupez les résultats avec les **fiches métadonnées** des indicateurs pour vérifier la
  fraîcheur et la qualité des données comparées.
