# Tableau de bord

La vue **Tableau de bord** donne une vue d'ensemble par territoire : chiffres clés,
évolution dans le temps, comparaison de périodes, tendances et alertes.

## Ce que vous trouvez sur la page

- Une **recherche** d'entrée (commune, cours d'eau, captage…).
- Les **chiffres clés** du territoire : valeur actuelle, tendance sur 10 ans, rang
  territorial, fraîcheur de la donnée.
- La **carte** du territoire avec sa légende (points de captage, périmètres de
  protection) et les **alertes actives**.
- Les graphiques d'**évolution annuelle** et de **comparaison de périodes**.

## Interface publique

Le bouton **« Interface publique → »** ouvre la version *grand public* de cette page :
même contenu (recherche, chiffres clés, carte, légende), présenté dans une interface
dédiée avec sa propre navigation horizontale et son en-tête.

- La navigation horizontale de l'interface publique n'affiche que les vues **publiques**
  (les vues réservées aux experts y sont masquées).
- Le bouton **« Espace experts → »** de l'en-tête public vous ramène au tableau de bord
  de l'application.

> L'interface publique partage exactement le même contenu que le tableau de bord :
> il n'y a pas deux jeux de données différents.
